Como funciona

  • Cadastre cada cliente com seu token Figma e File Key
  • Clique em "Ativar" no cliente desejado
  • Qualquer pessoa que abrir a ferramenta vai usar o cliente ativo automaticamente
  • O File Key está na URL do Figma: figma.com/design/FILE_KEY/...
  • O Token é gerado em: Figma → Settings → Personal access tokens
